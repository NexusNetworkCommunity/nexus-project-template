# Contributing

Thanks for helping build this project.

## Joining

You join from the project's page on Nexus. Nexus sends you an invitation to this GitHub
organization; once you accept it, you're added to the project's team and can push branches
here. Your access follows your role on Nexus, so role changes happen there, not on GitHub.

## Picking up work

- Start with the pinned "Ranked backlog" issue: work near the top matters most.
- Comment on an issue before you start, so two people don't do the same work.
- New here? Issues labelled `good first issue` are a good place to begin.

## Making a change

1. Create a branch from `main`.
2. Keep each pull request to one change, with a short note on what it does and why.
3. A maintainer reviews and approves it before it's merged.
4. `main` is protected: no direct pushes and no force-pushes.

Merged pull requests count toward your path on Nexus.

## Being a good teammate

Be kind and specific in reviews, and ask when something isn't clear. If there's a problem with
a person, tell the project's initiator or a Nexus moderator.
